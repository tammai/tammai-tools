Reference · shapes · connectors · layouts

Soft Visuals gallery

Every shape, connector and layout this skill supports. Each <svg> is self-contained — copy one out and it works anywhere the --dg-* tokens are defined, including a workshop-slides deck. Press T for light mode.

Shape library

One stroke width (1.75) and one corner radius (12) across every shape — that evenness is most of the style. Hue carries meaning, so keep it consistent within a visual and give only the focal node --dg-accent-fill.

Connectors

Draw connectors before the shapes so the line ends are painted over. Stop the path 4–6px short of the target so the arrowhead sits in the gap rather than touching the border.

Wireframe components

Wireframes drop the hues and work in --dg-surface / --dg-border greys. The accent marks one thing per screen — the primary action, or the active tab — never both. Copy stays as placeholder bars: real sentences make reviewers argue about the wording instead of the layout.

Wireframe frames

Pick the frame that matches the target, then lay the components inside it. Use class="figure narrow" for phone and watch frames so they do not stretch to the full canvas width.

Flowchart

A decision diamond with labelled edges is the spine. Failure paths take --dg-rose, the happy path stays neutral blue — colour does the explaining before anyone reads a label. Note the annotation hangs off a dashed leader with no arrowhead: arrows mean flow, and a note is not a step.

Architecture

A dashed group marks the trust boundary; cloud sits outside it, in its own hue — a third party is not the same kind of thing as your own compute, so it must not share the workers' colour. Datastores share one hue so they read as a tier. The dashed edge means async, and it starts at the gateway's own edge: a connector floating in the gap beside its source reads as belonging to nothing.

Wireframe — desktop

Wireframes drop the hues and work in --dg-surface / --dg-border greys, with a single accent for the primary action. Copy stays as wf_bar placeholder bars — real words invite bikeshedding about the words.

Wireframe — mobile

Same primitives at phone proportions. The active tab is the only element carrying the accent.

Org chart

Edges have no arrowheads — reporting is a relationship, not a flow. One hue per level so depth reads at a glance, and the accent goes on the root. The rounded bridge is a single path: up from each child, Q corner, along the bus, Q corner, down.

Sequence diagram

Participants sit in a header row over dashed lifelines; seq_activation bars show who is busy. Requests are solid and neutral, returns are dashed and mint — so you can read the round trips without following every label. Draw activation bars before the arrows so the arrowheads land on top.

Timeline / Gantt

A column grid sets the time axis; every bar is positioned and sized in column units (x = GX + cw * start), never by eye — that is what keeps the bars honest. One hue per workstream, and the only accent is the today marker.

Kanban board

Columns are --dg-surface containers; cards sit on --brand-bg so they read as lifted without needing a shadow. Tags carry the hue — the card itself stays neutral, otherwise four columns of coloured cards becomes noise.

User journey map

Stages are columns, lenses are rows. The Feeling row uses faces rather than words so the emotional dip is visible at a glance — that dip is the whole point of the artifact. Opportunities take a hue by sentiment: mint for a clear win, rose where the journey is actively losing people.

Mindmap

Centre node takes the accent; every branch owns one hue and its connectors and leaf underlines inherit it. Branches balance left and right so the centre stays centred. Leaves are text on a tinted rule rather than boxes — boxing every leaf turns a mindmap into an org chart.
